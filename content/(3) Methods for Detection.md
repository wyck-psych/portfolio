
[[(3.1) Anomaly detection]] refers to a set of approaches and methods for identifying observations which deviate from the rest of the data in a way that indicates that those observations are generated by a different mechanism. Anomaly detection methods have many applications in domains such as cybersecurity, test security, data quality, and identifying financial fraud. 

Anomaly detection approaches generally fall three categories based on the assumptions made about the dataset: supervised, unsupervised, and semi-supervised. Supervised approaches require a dataset with observations which are labeled as "normal" or "abnormal" (including multiple forms of abnormality). Supervised approaches are uncommon in anomaly detection applications because it is often difficult to define anomaly status precisely and assign ground truth labels to observations. Thus, labeled datasets are rare and difficult to collect. In contrast, unsupervised approaches use unlabeled data, often with the assumption that there are fewer anomalies than genuine observations. This makes unsupervised approaches more suitable for most anomaly detection problems. Lastly, semi-supervised approaches assume that some portion of the dataset is labeled. A common semi-supervised approach is to use a dataset containing only "normal" observations and then test the method using a dataset with some contamination. However, semi-supervised approaches in general may utilize various combinations of labeled or unlabeled observations.
