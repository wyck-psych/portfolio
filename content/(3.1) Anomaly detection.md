### Concepts

**What is an Anomaly?**
- An **anomaly** is an observation which deviate from the rest of the dataset in a way that indicates that it was generated by a different mechanism. 
- An **outlier** is a related term that is often used synonymously with anomaly. The term outlier is more common in statistical contexts where outliers are treated as contaminants which must be handled in order to achieve the main goal of drawing valid inferences from data. In contrast, anomaly is more common in applied settings (e.g. identifying fraud, cheating in tests, etc.) where understanding the anomalies themselves is the main goal. 
- A **novelty** generally refers to observations which a detection method has not seen before (e.g., been trained on). Novelty detection generally involves a semi-supervised approach where the method is trained on "normal" data and is then used to classify novelties. 


**Types of Anomalies**
- **Point anomaly**: An individual observation which is anomalous relative to the rest of the dataset. 
- **Contextual anomaly (a.k.a. conditional anomaly)**: An individual observation which is anomalous only within a particular context. E.g., a very low temperature is normal in the Winter but unusual in the Summer. 
- **Collective anomaly**: A set of observations which is only anomalous as a whole, even when its individual observations are not anomalous by themselves. E.g., an unusual sequence of events in a online platform. 


**Types of Approaches**
- **Supervised**: Utilizes a labeled training dataset where it is known whether each observation is "normal" or anomalous. 
- **Unsupervised**: Utilizes an unlabeled training dataset where it is unknown whether an observation is "normal" or anomalous. 
- **Semi-supervised**: Utilizes a training dataset in which some portion of the data (either "normal" or anomalous) is labeled. Typically, a completely "normal" dataset is used for training. 


**Key Questions for Anomaly Detection Algorithms**
- How is "normal" defined?
- Are there multiple types of "normal" and anomalous observations?
- What is considered a significant deviation from the norm?
- How do we incorporate multiple attributes per observation?
- How do we analyze changes that happen over time? 
- How can we design quantitative metrics in a principled way to unambiguously say which of two observations is more anomalous?
- How can we design algorithms in a principled way (e.g., based on mathematical or rational grounds)?
- How efficient is the algorithm and how good are the results given the computational cost?


**Key Assumptions of Anomaly Detection Approaches**
- **Stationarity**: The underlying processes that led to the generation of the training data are not significantly different from those in deployment. The statistics that characterized the system in the past continue to characterize the system in the future. 


**Key Issues in Anomaly Detection Problems**
- **Unbalanced Classes**: Datasets often contain far fewer anomalies than "normal" observations. 
- **Heterogeneous Classes**: Anomalies may have little in common with other anomalies. 
- **Local vs. Global Anomalies**: Some anomalies are global (e.g., an IQ score of 160 is 4 standard deviations above the mean), while other anomalies are local and are embedded within the range of "normal" values. 


**Evaluating Anomaly Detection Methods**
- **Confusion matrix**: Correct detection (TP, TN), false positive (FP), and false negative (FN) rates. 
- **Precision**: The proportion of identified anomalies which are true anomalies; TP/(TP+FP). 
- **Recall**: The proportion of true anomalies which are identified; TP/(TP+FN). 
- **Rank-power**: Most AD methods output an anomaly score which can be used to rank order the observations from most to least anomalous. Rank-power is a measure that ranges from 0 to 1 and indicates the degree to which the true anomalies are ranked at the top.

### Approaches to Anomaly Detection

**Distance-Based Approaches**
- Distance-based approaches identify observations as anomalous when they have a large distance to a collection of other points. The difficulty is then to specify the distance measure and the collection of comparison points in a principled way. 
- **Key questions for distance-based approaches:**
	- *How anomalous is a given observation?* This involves defining a function which takes the observation and outputs an anomaly score. 
	- *What is the absolute threshold for assigning anomaly status to observations?* This involves examining the distribution of anomaly scores and setting an absolute threshold.
	- *Is one observation more anomalous than another?* This involves comparing the anomaly scores of different observations and ordering them. 
	- *Which observations are identified as being the most anomalous in the dataset?* This involves examining the ordered list of anomaly scores. 
	- *Of the most anomalous observations in the dataset, how many exceed the absolute threshold?* 
	- *How might high dimensionality affect the outcomes?*
- **Distance measures:**
	- *Euclidean distance*: The straightline distance between two points in Euclidean space. For two n-dimensional vectors, Euclidean distance is calculated by taking each pair of corresponding features, squaring the difference, summing across all features, and taking the square root. 
	- *Minkowski distance*: Family of distance measures that generalizes Euclidean distance by setting the exponent to a parameter p which can vary (e.g., p = 1 is Manhattan distance, p = 2 is Euclidean distance, and p → ∞ is Chebyshev distance). 
	- *Mahalanobis distance*: Modifies Euclidean distance to account for the scales, variances, and correlations of variables. Essentially, the data is first transformed so that the features are uncorrelated and have unit variance. The Euclidean distance is then calculated between observations in this transformed space. 
	- *Cosine similarity*: Ignores magnitude and only examines the angle between the two vectors in space. Ranges from 1 (same direction) to 0 (orthogonal) to -1 (opposite direction). 
- **Distance-based methods**: 
	- *Distance to all points*: For each observation, find the distance to all other observations and use those values to compute an anomaly score. 
	- *Distance to nearest neighbor*: For each observation, find the distance to the nearest other observation in the dataset and use that value to compute an anomaly score. 
	- *Distance to k nearest neighbors*: Choose a parameter k representing neighborhood size. For each observation, find the distance to the k nearest other observations and use those values to compute an anomaly score. 


**Clustering-Based Approaches**
- Clustering-based approaches identify clusters in the dataset, which are sets of observations which are similar to each other and dissimilar from other observations. In general, "normal" observations are expected to be near centroids of clusters, while anomalies are expected to be far away. Clusters may be formed using a variety of approaches, including using distance measures. Some clustering algorithms also allow for points to not belong to any cluster, or to belong to multiple clusters simultaneously. 
- **Key questions for clustering-based approaches:**
	- How many clusters are there?
	- How large should clusters be?
	- How much computational power is needed?
	- How much sample size is needed?
- **Clustering-based methods**:
	- *[[K-means Clustering]]*: First, choose a parameter k representing the number of clusters. Then, randomly select k observations to be the initial centroids. For each observation, find the Euclidean distance to the nearest centroid and assign that observation to the centroid. Next, once all observations are assigned to clusters, update each centroid to a new value using the mean of the observations assigned to that cluster. Repeat this process until the number of reassignments in an iteration falls below a specified threshold. 
	- *[[Fuzzy Clustering]] (a.k.a. soft k-means)*: Essentially a modification of k-means clustering where the contribution of each observation is weighted by how far it is from a centroid. Points closer to a centroid are given more weight while points far away are given less weight. 
	- *Agglomerative and Divisive Clustering*: Agglomerative clustering approaches start with many tiny clusters and successively merges them to form bigger clusters. First, start with each observation as its own cluster. Next, find the two clusters that are the closest to each other and merge them into a single cluster; this step may also involve combining multiple clusters. Repeat until all nodes have been merged or some other termination condition is met. Agglomerative clustering is also called a "bottom-up" approach, as it starts with each observation as an individual cluster. In contrast, *divisive clustering* is called a "top-down" approach, as it starts with all observations in a single cluster and partitions it into subsets. This is done by repeatedly applying the k-means clustering algorithm with k = 2. Together, the two approaches are called [[Hierarchical Clustering|hierarchical clustering]]. 
	- *Density-Based Agglomerative Clustering*: The density-based spatial clustering of applications with noise [[DBSCAN Algorithm|(DBSCAN)]] algorithm is a density-based agglomerative clustering algorithm designed to discover clusters in noisy datasets without specifying the form of the clusters or the number of clusters in advance. 


**Model-Based Approaches**
- Model-based approaches allow for the parameters and predictions of models fit to the dataset to be used as additional inputs for anomaly detection methods. Model parameter space approaches assign anomaly status to observations based on how much they influence model parameter estimates. This is done by comparing the parameter estimates for the full dataset and a reduced dataset, which may be formed by removing an observation or by taking a small subset of the full dataset. The differences in parameter estimates between the full and reduced datasets can be combined to create an anomaly score for each observation. Model data space approaches assign anomaly status to observations which exhibit significant model misfit. 
- **Model-based methods**: 
	- *Distribution models*: The observations are modeled using a known parametric distribution, such as a normal distribution, and the model parameters are learned from the training data. Assuming that the distribution model is a valid representation of the data, the model provides principled and interpretable ways to assign anomaly status. For anomaly detection, *mixture models* are especially relevant. 
	- *Regression models*: In general, regression models state outcome variable(s) as some function of predictor variable(s) and an error term. Regression models are used for supervised learning problems and involve a labeled training dataset. Regression models are typically trained using some form of gradient descent in which a loss function is minimized. 
	- *[[(2.1.1) Time Series Data|Time series models]]*: A time series is a totally ordered sequence of observations which are each associated with a time-stamp. Time is a unique feature that requires special attention because it introduces dependence in the observations, it carries information about the order and spacing of the observations, and time series data may be generated by non-stationary processes. The main anomaly detection approaches for time series / sequence data are: 
		- *Kernel-based techniques*: Computes an anomaly score based on the entire time series sequence. These anomaly scores can then be used with traditional anomaly detection methods. 
		- *Window-based techniques*: Analyzes short windows (subsequences) of each time series, computes a score for each subsequence, and then combines them to form an anomaly score. Window-based techniques are better than kernel-based techniques for detecting local anomalies. However, window size is a hyperparameter that must be specified. 
		- *Markovian techniques*: Assigns probabilities to each subsequence based on previous observations. Instead of using the full observation history (which is impractical), Markovian techniques assume that only the most recent k states matter for detection. In the simplest case, k = 1, only the current state matters for predicting the next state.
